# Crisis Risk Assessment

一个面向企业、品牌和机构舆情危机的结构化风险评估 Skill。

它使用八维模型完成事实确认、责任判断、危机归类、传播研判、公众心理识别和衍生风险分析，并输出红、橙、黄、蓝综合等级、升级条件及优先处置方向。

## 能做什么

- 把零散、冲突或不完整的信息整理成事实确认卡；
- 区分企业责任、事件范围、传播态势和衍生风险；
- 识别主要公众情绪及其解除条件；
- 生成适合管理层、公关、法务和业务部门共同使用的风险评估报告；
- 在信息不足时给出等级区间、条件分支和核实清单。

## 安装

把整个仓库目录复制到 Codex 技能目录：

```bash
cp -R crisis-risk-assessment ~/.codex/skills/crisis-risk-assessment
```

安装后重新开始一个对话，使技能进入可发现状态。

## 使用

显式调用示例：

```text
用 $crisis-risk-assessment 评估这起企业舆情的整体风险，并给出红橙黄蓝定级。
```

也可以直接提出“评估这起舆情风险”“判断危机等级”“做八维分析”等需求，由系统自动匹配。

## 使用边界

本 Skill 提供特定时间点的决策辅助，不替代事实调查、法律意见、监管结论或企业最终决策。对实时事件进行判断时，应优先核验企业声明、监管文件、平台原帖和权威媒体报道。
