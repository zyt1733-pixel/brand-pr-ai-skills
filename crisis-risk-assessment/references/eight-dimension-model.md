## 1. 使用原则

本参考文件采用智猫 v2.1 八维推理模型整理。若模型以后更新，先核对新旧差异，再更新本参考文件。

八个维度依次分析，最后才综合定级。事实还原是基础；事件源头、责任和危机类型完成定性；范围、传播、公众心理和衍生风险完成程度与后果判断。

## 2. 维度一：事实还原

### 作用

建立后续所有判断的事实底座。

### 五项因素

| 因素 | 判断内容 |
|---|---|
| 时间 | 事件发生、公开和发酵的时间 |
| 地点 | 线上平台、线下门店、地区或业务范围 |
| 主体 | 企业、当事人、受害方、爆料方、合作方 |
| 事件 | 客观发生经过 |
| 原因 | 已确认原因、可能原因与待调查原因 |

### 规则

- 只还原事实，不在本维度评价动机和责任。
- 用户没说、公开来源也查不到的内容标“待确认”。
- 用户陈述与公开资料冲突时并列呈现。
- 标注事件卡的最后更新时间。

## 3. 维度二：事件源头与动机

### 作用

判断谁把事件带入公共讨论、他为何发声、企业真正需要回应谁。

### 九类事件源头

1. 政府监管；
2. 媒体或自媒体；
3. 用户或消费者；
4. 竞争对手或恶意方；
5. 公司自身或员工；
6. 合作方或供应链；
7. 投资者或股东；
8. 公众意见领袖；
9. 职业打假人。

### 五类动机

| 动机 | 识别信号 |
|---|---|
| 直接利益 | 索赔、勒索、竞争打压或明确利益要求 |
| 真实诉求 | 存在可核验的受损事实，需要解决问题 |
| 间接利益 | 借势涨粉、抢夺话语权或商业曝光 |
| 情绪宣泄 | 语气强烈但没有清晰解决诉求 |
| 误解失实 | 事实不完整、理解偏差或信息被错误拼接 |

### 五步判断

```text
识别身份
→ 判断动机
→ 提炼核心需求
→ 判断合理需求能否满足
→ 确定回应对象与基本姿态
```

动机不明时，默认按“可能存在真实诉求”保守处理，不预设对方恶意。

## 4. 维度三：企业责任

### 作用

确定认错力度、承担动作、整改深度和后续出面层级。

### 五档责任

| 内部档 | 责任画像 | 用户报告用语 |
|---|---|---|
| L1 | 决策层明知或主导，问题系统性存在 | 企业承担全部或主要根本责任 |
| L2 | 非明知，但管理、培训、监督或产品质量严重失职 | 企业承担主要责任 |
| L3 | 单店、单员工或单点失控，公司存在管理责任但非主因 | 企业承担部分责任 |
| L4 | 企业行为本身无直接过错，但监督或关联方管理存在漏洞 | 企业可能承担监督或连带责任 |
| L5 | 被造谣、误伤或外部事件牵连，且无明显监督漏洞 | 暂未发现企业责任 |

### 分界线

- L1与L2：是否明知并由决策层主导。
- L2与L3：是否为系统性失控。
- L3与L4：企业行为本身是否有错。
- L4与L5：企业是否存在监督漏洞。

### 历史升档

- 过去三年一次同类危机：责任升一档。
- 过去三年两次以上同类危机：责任升两档。
- 仅统计性质相同或根因相同的危机，不把任意负面都算作同类历史。

### 内部色级映射

| 责任档 | 色级 |
|---|---|
| L1 | 红 |
| L2 | 橙 |
| L3 | 黄 |
| L4或L5 | 蓝 |

## 5. 维度四：危机类型

### 作用

识别事件属于哪种根因，以便后续匹配正确的策略方向。

### 五类风险与一个兜底类

| 类型 | 识别重点 |
|---|---|
| 战略选择型 | 商业模式、价值取舍、利益分配或重大决策本身引发争议 |
| 业务执行型 | 产品、服务、流程、审核或一线执行出现问题 |
| 内部治理型 | 高管、员工、劳动关系、组织文化或内部制度问题 |
| 外部关联型 | 供应链、加盟商、代言人、投资对象或合作伙伴牵连 |
| 外部侵害与误解型 | 谣言、黑公关、恶意攻击、事实拼接或群体误解 |
| 复杂兜底型 | 多类型交叉，或信息不足以可靠归类 |

### 规则

- 先判断根因，不以表面话题归类。
- 主类型只选一个，可补充一个次类型。
- 不输出内部场景编号。
- 没有102场景映射表时，不假装已经命中具体预制场景。

## 6. 维度五：事件范围

### 作用

判断问题本身存在多大范围，决定整改规格和协同深度。

| 内部档 | 问题范围 | 内部色级 |
|---|---|---|
| L1 | 集团级、商业模式或全公司制度问题 | 红 |
| L2 | 一条核心业务线 | 橙 |
| L3 | 多门店、多区域或多个团队 | 橙 |
| L4 | 单一门店、单一区域或单一部门 | 黄 |
| L5 | 单一员工、单一批次或单一事件 | 蓝 |

事件范围与传播范围必须分开。一个单店问题可以全网传播；一个集团问题也可能暂时没有公开。

## 7. 维度六：传播态势

### 作用

判断传播有多强、处于什么阶段、主战场在哪里，并据此判断响应紧迫度。

### 三个子项

```text
传播当量 = MAX（媒体关注度、新媒体热度、意见领袖影响力）
```

### 媒体关注度内部判断

| 色级 | 内部参考 |
|---|---|
| 红 | 高覆盖权威媒体已经问询或报道 |
| 橙 | 多家全国性或高影响力媒体跟进 |
| 黄 | 少量地方或行业媒体跟进 |
| 蓝 | 单一低量级媒体或零星问询 |

用户报告不得出现“一级媒体、二级媒体”等内部称谓。

### 新媒体热度内部参考

平台数据变化快，优先使用用户提供的实时数据与平台当前口径。以下只作内部参考：

| 色级 | 微博 | 抖音或视频号 | 小红书或头条 | 微信公众号 |
|---|---|---|---|---|
| 红 | 热搜总榜前3且负面原创5000以上 | 热搜前3或互动10万以上 | 互动5万以上或头条前5 | 多篇10万以上刷屏 |
| 橙 | 热搜总榜前10且负面原创2000以上 | 互动3万以上 | 互动1万以上 | 阅读10万以上 |
| 黄 | 城市热搜前3且负面原创1000以上 | 互动5000以上 | 互动2000以上 | 阅读1万以上 |
| 蓝 | 热搜总榜前50且原创1000以上 | 互动2500以上 | 互动500以上 | 阅读3000以上 |

没有精确数据时，使用“低、中、高、极高”定性，不伪造互动数。

### 意见领袖影响力内部参考

| 色级 | 参考量级 |
|---|---|
| 红 | 单个千万级账号，或多个跨圈层头部账号形成共振 |
| 橙 | 500万至1000万量级账号，或多个中腰部账号同向发声 |
| 黄 | 100万至500万量级垂类账号 |
| 蓝 | 10万至100万量级账号 |

跨圈层同向发声、与品牌有合作纠纷史、账号正处于流量上升期，均增加传播风险。

### 五个传播阶段

1. 萌芽期：单一来源、零星讨论、无媒体。
2. 初步报道期：少数媒体或一个重要账号跟进。
3. 爆发期：热搜、多平台、多家媒体。
4. 议题流变期：焦点从事件转向价值观、行业或社会议题。
5. 消退期：热度持续下降且没有新信息。

### 响应紧迫度

| 传播色级 | 首次信息更新参考 |
|---|---|
| 红 | 尽量在4小时内提供首次有效信息 |
| 橙 | 尽量在12小时内提供首次有效信息 |
| 黄 | 视风险在24小时内更新 |
| 蓝 | 不强制公开回应，持续观察 |

“首次有效信息”不等于仓促定责，可以是关切、已采取动作、调查安排和下次更新时间。

## 8. 维度七：公众心理

### 作用

识别公众的主要情绪准备状态，找到解除条件，而不是只增加解释信息。

| 情绪簇 | 典型潜台词 | 解除条件 | 禁忌 |
|---|---|---|---|
| 安全恐惧 | 我会不会成为下一个 | 给出可执行的安全办法、范围和时间表 | 只讲概率低、不必恐慌 |
| 愤怒不公 | 凭什么、谁来负责 | 修复边界、追责与补偿同步 | 先说企业也是受害者 |
| 不确定焦虑 | 到底怎样、为什么一直拖 | 给事实骨架、固定更新节奏和可见进度 | 沉默或只说正在调查 |
| 厌恶嫌恶 | 太脏、太恶心、不能接受 | 切割污染源、展示清理过程和证据 | 只说个别现象 |
| 慈悲怜悯 | 先把人照顾好 | 医疗、家属、心理和尊严照护 | 把悲剧当品牌传播素材 |
| 失望信任 | 原来这个品牌也是这样 | 可核验事实、行动兑现和老用户补救 | 空喊一贯重视 |
| 羞耻屈辱 | 企业没有尊重我们 | 更高层级道歉、处理责任人、先人后事 | 教育用户或群体 |
| 渴望被看见 | 反馈多次为什么没人理 | 一对一关怀、公开承认诉求 | 只回应大账号 |
| 好奇惊诧 | 到底谁在说真话 | 给事实骨架和连续更新 | 一次发布冗长通报 |
| 蒙羞服从 | 我要与事件划清界限 | 主动为关联方减压、提供解绑通道 | 把关联方继续拖下水 |

默认先识别不确定焦虑，再判断是否分化为另一种主导情绪。最终选择一至两个主导情绪，不堆满十类。

必须规避五种误区：

1. 真相陷阱；
2. 人性缺失；
3. 鄙夷态度；
4. 企业受害者心态；
5. 居高临下。

## 9. 维度八：衍生风险

### 作用

判断事件继续发展会伤到企业哪里，以及哪些利益相关方需要优先化解。

### 四类衍生风险

| 风险 | 红色参考 | 橙色参考 | 主要协同部门 |
|---|---|---|---|
| 监管 | 国家级立案、吊销许可、重大行业性影响 | 省级执法、重大罚款或示范效应 | 政府事务与法务 |
| 财务 | 股价大幅下跌、亿级退赔、重大融资影响 | 明显股价波动、千万级退赔 | 投资者关系与财务 |
| 经营 | 核心业务叫停、大规模关店或用户流失 | 业务线销售明显下滑、合作方撤离 | 业务部门 |
| 法律 | 影响业务合法性、行业准入或大规模群体诉讼 | 重大案件或中等规模群体诉讼 | 法务 |

没有可靠损失数据时，不使用具体金额或百分比定级。

### 七类受影响人群

| 人群 | 核心关切 | 不化解的后果 | 主要负责方 |
|---|---|---|---|
| 直接受害者 | 公平、被看见、实质补救 | 继续曝光、诉讼、集体行动 | 业务 |
| 公众情绪场 | 安全、公平、情绪出口 | 抵制和社会扩散 | 公关 |
| 监管部门 | 合规、秩序、风险是否可控 | 调查、处罚、业务限制 | 政府事务与法务 |
| 投资者 | 经营确定性和风险边界 | 股价、融资和信心波动 | 投资者关系 |
| 媒体 | 事实、公共价值和进展 | 深度调查和持续报道 | 公关 |
| 合作伙伴 | 是否被连带、合作是否安全 | 切割和终止合作 | 业务 |
| 内部员工 | 事实边界和组织信心 | 泄密、爆料、离职 | 人力与管理层 |

## 10. 综合定级

### 公式

```text
综合定级 = MAX（企业责任色级、事件范围色级、传播态势色级、衍生风险最高色级）
```

### 强制规则

- 传播态势为红，综合为红。
- 死亡、重伤或群体入院，综合为红。
- 敏感群体、三层共振、忽视明确外部预警，触发一项升一档。
- 特殊敏感时期只增加谨慎提示，不自动升档。
- 最高不超过红色。

### 四色含义

| 色级 | 含义 |
|---|---|
| 红 | 需要公司最高级资源迅速介入，存在整体品牌或重大现实损失风险 |
| 橙 | 对核心业务或品牌形成较大伤害，需要高级别跨部门响应 |
| 黄 | 影响集中在局部，需要部门级响应并防止升级 |
| 蓝 | 当前影响较小，可按常规流程处理并持续观察 |

综合色级表达资源投入和处置紧迫度，不等于责任结论。
