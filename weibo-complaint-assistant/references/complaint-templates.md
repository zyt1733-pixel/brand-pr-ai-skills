# 微博投诉交付模板

## 目录

1. 用户引导语
2. 固定交付顺序
3. 被投诉微博信息卡
4. 微博投诉操作指引
5. 正式企业微博投诉函

## 1. 用户引导语

用户未提供必要材料时，使用且只使用以下简短引导：

> 请发送**具体微博链接**并简要说明投诉理由；如有截图、文件等相关证据，请一并提供。资料不全不影响初步处理，我将根据现有材料提供投诉类型建议、投诉函及操作指引。

用户已经提供微博链接或截图及投诉理由时，不重复该引导，直接分析。

## 2. 固定交付顺序

完成版答案只输出以下三个大标题：

1. 一、被投诉微博信息卡
2. 二、微博投诉操作指引
3. 三、微博投诉函

大标题统一使用 `##`；标题下只使用加粗标签、序号和正文建立层级。不再把事实对照、类型匹配、投诉理由和补充证据拆成独立大标题。

用户只要某一部分时，可仅输出用户明确要求的部分。

## 3. 被投诉微博信息卡

```markdown
## 一、被投诉微博信息卡

- 被投诉账号：【账号名称】
- 账号 UID：【UID／未获取】
- 账号主页：【主页链接／未获取】
- 被投诉微博链接：【具体微博原始链接】
- 微博 ID：【ID／未获取】
- 发布时间：【时间／未获取】
- 内容摘要：【中性概括，不复制非必要敏感细节】
- 互动数据：转发【数值／未获取】，评论【数值／未获取】，点赞【数值／未获取】
- 信息来源：【微博公开页面／用户截图／用户说明】
- 采集状态：【完整／部分字段未获取／公开页面暂无法读取】
```

不将转评赞作为必填项，也不根据互动数据自动推断侵权程度。

## 4. 微博投诉操作指引

将官方链接只放在本部分：

```markdown
## 二、微博投诉操作指引

微博官方投诉入口：
https://service.account.weibo.com/h5/roles/zone

投诉对象：【该条微博／账号信息】

**主投诉路径**

【一级投诉类型】→【页面二级具体原因】（具体行为：【第三层行为判定】）

**可直接粘贴的投诉理由**

【用一段话一次性说清：被投诉内容说了什么、真实情况或具体违规是什么、有哪份直接证据、为何符合上述路径、请求平台如何处理。不再另写“选择理由”。】

**建议上传证据（有则列）**

- 【直接证据名称】：用于证明【具体事实】。

**备用投诉路径**

【备用一级类型】→【备用二级具体原因】（具体行为：【行为判定】）

适用条件：【主路径在当前页面不可选，或补充某类证据后才使用】。

可粘贴理由：【只保留与备用类型直接相关的简短理由，不照抄主理由】。

**操作步骤**

1. 打开上述官方入口，或在目标微博右上角点击“…”后选择“投诉”。
2. 依次选择上述一级类型和二级具体原因。
3. 粘贴对应的投诉理由，并上传现有直接证据。
4. 按当前页面的按钮名称和材料要求提交。
```

输出时遵守：

- 主投诉理由本身同时承担事实对照、分类依据和可粘贴文案三个功能，不再重复写三遍。
- 没有必要的备用类型时，整段删去，不为形式完整而硬凑类型。
- “建议上传证据”只列用户已提供或明确可获取的直接材料；没有时整段省略，不写空占位项。
- 企业类事实优先使用公司盖章情况说明、内部通知、业务系统记录、合同或原始沟通记录。仅转述公司回应的媒体报道或截图不作为证明真伪的核心证据。
- 如建议路径与用户最初主张不一致，在主路径下用一句“调整说明”交代原因，不再生成独立的类型匹配报告。

## 5. 正式企业微博投诉函

参照企业撤稿函的正式结构：首先称呼微博平台合法运营主体“北京微梦创科网络技术有限公司”，一段锁定投诉对象、原始链接和公司总体核查结论，再逐条论证被投诉表述、公司事实、投诉类型与具体危害，最后只提出删除内容这一项聚焦请求。结构必须紧凑，但论证不得过于简略。

```markdown
## 三、微博投诉函

**关于微博账号【账号名称】发布【失实／侵权／违规】内容的严正投诉函**

致：北京微梦创科网络技术有限公司

【发布日期／近日】，微博账号【账号名称】发布【对被投诉内容的最少必要概括】，原始链接：【必填；无法获取时写待补充】。经我司对【相关制度、通知、业务记录或事件情况】进行全面核查，该内容【与客观事实严重不符／存在明显侵权或违规问题】。我司对此予以严正否认，并正式提出投诉。

具体情况如下：

1. **【核心问题一：如编造并传播虚假事实】**

   该微博称“【最少必要引用】”。但经我司全面核查，我司【从未发布、制定、传达或执行某项政策／实际情况为……】。我司始终【依法合规经营／尊重并保障员工合法权益／履行相关法定或社会责任】。【如有直接证据：上述事实可由【证据名称】予以证明，见附件。】因此，被投诉表述毫无事实依据，属于【不实信息—造谣传谣／其他已匹配类型】。该内容容易【误导员工和公众、制造焦虑恐慌、干扰正常劳动关系和企业经营秩序】，并损害我司及相关人员名誉。

2. **【核心问题二：如恶意贬损、侮辱或诽谤】**

   该微博还使用“【侮辱、贬损或恶意标签化原文】”等表述。该评价建立在上述虚假事实之上，并非对企业经营行为的客观评论，而是对【企业／企业管理人员】的侮辱性标签和恶意贬损，具有明显的诽谤性、侮辱性和名誉贬损性质，符合【人身攻击—不友善言论／已匹配类型】的行为特征。此类表述不仅严重损害【企业及相关管理人员／企业家】的合法名誉，也容易诱导不明真相的用户跟风攻击，进一步扩大不良影响。

3. **【传播危害与我司立场】**

   互联网并非法外之地。以无法核验的网络传言为依据编造、传播虚假信息，并对【企业及相关管理人员／企业家】进行恶意攻击，不仅会扰乱企业正常经营和劳动关系，也会污染网络信息生态、加剧公众误解与社会焦虑，造成不良社会影响。我司始终坚持【依法合规经营、保障员工合法权益、履行企业社会责任】，对任何编造、传播不实信息以及恶意损害我司和相关人员名誉的行为，坚决反对并严正维权。

鉴于上述内容事实严重失实、性质恶劣且已对我司合法权益及正常秩序造成不良影响，我司现严正要求贵司立即删除被投诉微博及微博平台内的相关转载、转发内容。

我司将继续对相关不实内容进行证据保全，并保留依法追究相关发布者、传播者责任的权利。

投诉人：【企业登记全称】

（请加盖公司公章）

日期：【年月日／待补充】
```

投诉函写作规则：

- 不再设置“投诉事项”“被投诉内容”“证据与事实对应”“适用的投诉类型”“造成的影响”等重复章节；但必须在每个核心问题内论述对应类型和现实危害。
- 投诉函为了可独立提交，可再次出现账号名称和原始链接；其余内容尽量不与第二部分逐字重复。
- 微博投诉函的默认收函称呼必须是“致：北京微梦创科网络技术有限公司”。该公司为微博官方公示的平台合法运营主体；正式寄送前如有主体变更，应再以最新官方公示核验。
- 有证据时，将证据名称放在它所证明的事实后，不另建空泛的证据章节。无证据时删除证据句，并将结论限定为“根据现有材料”或“请平台核查”。
- 当被投诉行为是侮辱、隐私泄露、骚扰或其他无需证伪的行为时，将逐条结构改为“具体行为＋原文或截图证据”，不强行写“实际情况”。
- 每个问题点都必须回答：对方说了什么、公司核查事实是什么、符合哪个投诉类型、会造成什么具体危害。通常保留 2–4 个核心问题，论证必须充分，不用一句结论代替事实说明。
- 在材料支持时表达公司正式立场，如依法合规经营、保障员工合法权益、履行企业社会责任；不写与争议无关的空泛品牌宣传。
- 对社会影响建立具体因果链：虚假信息扩散 → 误导员工和公众 → 制造焦虑恐慌或诱发攻击 → 干扰劳动关系、企业经营与网络信息秩序 → 造成不良社会影响。缺少相关事实时，不直接使用“危害社会稳定”等过度拔高的表述。
- 有公司核查结论或盖章函支持时，使用“毫无事实依据”“属于造谣传谣”“性质恶劣”“我司严正要求”等坚定表达。只有用户单方陈述时，将表达自动降级为“根据现有材料”“涉嫌”或“请平台核查”。
- 企业主体投诉时，投诉人必须填写企业登记全称，署名下方标注“请加盖公司公章”。如未提供全称，写“企业登记全称：待补充”，不擅自缩写或虚构。
- 结尾必须使用明确、严正的要求句，将请求聚焦为“立即删除被投诉微博及微博平台内的相关转载、转发内容”，不再分点罗列审核、阻断传播、处理账号、反馈结果或保存记录等要求。已进行证据保全或准备维权时，可在下一句声明保留追究相关发布者、传播者责任的权利。
- 不要要求北京微梦创科网络技术有限公司删除微博平台以外的网站内容，因其无权直接处理其他平台。
- 截图应保留账号名称、发布时间、完整上下文和原始链接；上传前遮挡与投诉无关的个人敏感信息。
