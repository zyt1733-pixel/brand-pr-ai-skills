# 内容发布风险审查输出规则

根据任务复杂度选择快速审查、完整审查或修改后复审。

## 一、快速审查

适用于一句文案、标题、Slogan 和海报短文案。

输出：

```text
发布结论
可以发布 / 修改后发布 / 暂缓发布，先核实 / 高风险，不建议发布

一句话判断
直接说明最重要的理由。

核心风险
指出最关键的一至三个问题，以及对应的具体文字或画面。

最容易被截图的内容
写出具体文字或画面；没有明显截图风险时明确说明。

建议修改
给出可以直接替换的版本；不是措辞问题时给出重写方向。
```

## 二、完整审查

适用于文章、视频脚本、营销活动、新闻稿、声明和复杂海报。

输出：

```text
发布结论
给出四级结论。

一句话判断
说明决定结论的最大理由。

一、内容意图
说明内容原本想表达什么，不替内容美化。

二、核心风险
每项风险写清楚：
- 触发风险的具体文字、画面或动作。
- 所属风险域。
- 外部可能怎样理解。
- 可能造成什么后果。
- 属于措辞、表达框架还是事实与动作问题。

三、传播放大测试
普通受众第一反应：
相关群体可能感受：
最容易被截图的文字或画面：
可能出现的媒体或自媒体标题：
评论区可能形成的主要争议：

四、事实与授权
已确认：
待核实：
需要补充的证据、授权或审批：

五、处理建议
必须停止或删除：
必须修改：
必须核实：
可以优化：

六、修改稿
能够通过修改解决时，提供一版完整修改稿。
事实、授权和企业行动不明确时使用【待确认】或【待补充】留位。
```

## 三、修改后复审

复审只回答：

- 原风险是否已经消除。
- 是否产生新的风险。
- 当前发布结论。
- 仍需处理的最后事项。

不要重复整份首次审查报告。

## 四、通过时的输出控制

内容可以发布时，不为显得专业而列出大量低概率风险。可以简洁输出：

- 可以发布。
- 判断依据。
- 一至两项可选优化。
- 必要的授权或发布提醒。

## 五、高风险时的输出控制

内容高风险时：

- 结论放在最前面。
- 不用委婉语言掩盖风险。
- 区分能否通过改字解决。
- 不在事实或动作有问题时只提供更安全的包装。
- 用户要求保留高风险钩子时，说明保留后的具体代价。

## 六、判断约束

- 单一重大风险可以直接决定结论，不能被多个低风险项抵消。
- 不输出综合风险分或百分制分数。
- 不把内部审慎判断写成法律定罪。
- 不编造外部反应，模拟标题必须有内容依据。
