# 内容发布风险审查 Skill

对准备公开发布的文案、海报、图片、视频脚本、新闻稿、企业声明、产品包装和营销活动进行发布前风险审查。

它不以敏感词数量或机械评分代替专业判断，而是从风险内容、传播语境、受影响群体、截图放大、事实依据和授权状态等方面给出明确发布结论。

## 主要能力

- 检查公共敏感与重大议题风险。
- 检查平等、群体尊严和价值表达风险。
- 检查字体、图片、音乐、肖像、原创和隐私授权。
- 检查色情、暴力、赌博、伪科学、恶搞和公共秩序风险。
- 检查事实、数据、产品功效、企业行动和品牌承诺。
- 模拟普通受众、相关群体、截图传播、媒体与对立方四种视角。
- 区分措辞问题、表达框架问题和事实或动作问题。
- 输出可以发布、修改后发布、暂缓核实、高风险不建议发布四级结论。

## 安装

将整个目录复制或克隆到 Codex 技能目录，并保证最终路径为：

```text
~/.codex/skills/content-publication-risk-review/SKILL.md
```

重新开启一个任务后即可被自动发现，也可以显式调用：

```text
$content-publication-risk-review
```

## 使用方式

可以直接提交：

- 一句文案或标题。
- 一篇文章、声明或新闻稿。
- 一张海报、产品图或社交媒体截图。
- 一段视频脚本或活动方案。
- 修改后的内容，请求再次复审。

示例请求：

```text
请用 $content-publication-risk-review 审核下面这段准备发布的内容，告诉我能不能发、主要风险和修改建议。
```

## 输出

根据内容复杂程度输出快速审查、完整审查或修改后复审，始终先给出明确结论：

- 可以发布。
- 修改后发布。
- 暂缓发布，先核实。
- 高风险，不建议发布。

## 测试

本项目不依赖第三方 Python 包。在仓库根目录运行：

```bash
python3 -m unittest discover -s tests -v
```

仓库推送或提交 Pull Request 时，GitHub Actions 也会自动运行上述测试。

测试会检查文件完整性、风险范围、四级结论、传播四镜、UI 元数据，并确保正式规则不包含具体品牌事件或外部链接。

## 边界

- 本 Skill 提供内容传播与舆情风险参考，不替代正式法律意见、广告审查和监管合规结论。
- 没有使用具体品牌事件作为判断材料。
- 没有使用机械百分制评分。
- 涉及视觉素材时需同时检查权利状态和画面语义。
